# 情報設計 (IA)

## URL構造

| パス | 内容 | 種別 |
|---|---|---|
| `/` | 自己紹介を中心にしたポートフォリオトップ | 静的・プリレンダリング対象 |
| `/blog` | 技術記事一覧 | 静的・プリレンダリング対象 |
| `/blog/$slug` | 技術記事詳細 | Firestore駆動・プリレンダリング対象 |
| `/projects` | 制作実績一覧 | 静的・プリレンダリング対象 |
| `/projects/$slug` | 制作実績詳細 | Firestore駆動・プリレンダリング対象 |
| `/admin` | 管理画面トップ（ログイン後ダッシュボード） | プリレンダリング対象外 |
| `/admin/login` | 管理者ログイン | プリレンダリング対象外 |
| `/admin/articles` | 技術記事のCRUD | プリレンダリング対象外 |
| `/admin/projects` | 制作実績のCRUD | プリレンダリング対象外 |

## ナビゲーション（ヘッダー）

- 技術記事一覧（`/blog`）
- 制作実績一覧（`/projects`）
- 自己紹介（`/` トップページ内のセクションへのアンカーリンク。独立した `/about` は作らない）

## CMS / 静的の切り分け

- Firestore管理（CMS）: 技術記事、制作実績
- 静的（リポジトリ内コンテンツ）: トップページの自己紹介セクション

## プリレンダリングとの関係

- `/admin` 配下は公開コンテンツページのパスと完全に接頭辞を分け、prerenderの `crawlLinks` から除外する対象を明確にする
- 公開ページ（`/`, `/blog`, `/blog/$slug`, `/projects`, `/projects/$slug`）から `/admin` 配下へのリンクは一切張らない
